편집 보조창의 그림 입력 탭을 이용하여 그림을 입력할 수 있습니다. 그림이 있는 경로로 이동하여 그림을 드래그하여 본문에 넣으면 됩니다.
최근에 실행된 메뉴 항목을 보려면 편집 보조창의 빠른 메뉴 탭을 이용하십시오. 최근 실행된 메뉴를 실행 시간/실행 횟수에 의해 구분 정렬해 볼 수 있고 클릭하면 해당 메뉴가 실행됩니다.
Intelli-Mouse를 사용하시면 본문에서 휠을 굴려 보십시오. 본문이 스크롤됩니다. 대화상자나 서체창을 열고 휠을 굴리면 해당 리스트 상자가 스크롤됩니다.
Intelli-Mouse를 사용하시면 [Ctrl]키를 누른 상태에서 휠을 굴려 보십시오. 보다 간편한 편집화면 크게 보기/작게 보기를 할 수 있습니다.
Intelli-Mouse를 사용하시면 [Ctrl]키를 누른 상태에서 휠을 누르고 마우스를 움직여 보십시오. 스크롤바 없이 편집화면 안에서 자유롭게 보는 위치를 바꿀 수 있습니다.
라벨 인쇄 위치 조정 : "도구(T)" 메뉴의 "라벨 만들기(L)"를 사용하면 다양한 모양의 라벨을 손쉽게 만들 수 있습니다. 라벨 용지의 중간 위치부터 인쇄하려면 "라벨 만들기"에서 "상세 정보" 버튼을 누른 다음 "인쇄 위치"를 조정하십시오. 
다른 회사의 라벨 규격을 사용하려면? : 제공되는 라벨 이외에 다른 회사의 라벨을 등록하여 사용할 수 있습니다. 라벨 제조회사에 문의하시기 바랍니다.
사용자 정의 라벨 사용 : 사용자가 새롭게 정의한 라벨의 규격을 사용할 수 있습니다. "라벨 만들기"에서 "라벨 정의"버튼을 사용합니다.
메일 머지 조사 자동 변환 : 찾기/바꾸기 뿐만 아니라 메일 머지/라벨 만들기에서도 조사의 자동 변환이 제공됩니다.
문자표 : 특수 문자, 기호 문자, 한자, 일본어 등은 "입력(I)" 메뉴의 "기호 문자(S)", "문자표(C)" 또는 "F2" 키를 사용하여 쉽게 입력할 수 있습니다.
최근 사용한 특수 문자 목록 : 최근 사용한 특수 문자는 "기본 도구"바에 특수 문자 아이콘을 누르면 표시되고 선택할 수 있습니다.
한글 윈도우 95에서 제공하지 않는 확장 한자 사용 : KS 상용 한자 및 확장 한자는 "입력(I)" 메뉴의 "기호 문자(S)", "문자표(C)"를 사용하여 입력할 수 있습니다.
도표 셀 이동  : 도표 셀의 크기를 자유 자재로 조정할 수 있습니다. <마우스로 셀 경계선 이동> : 선택한 셀과 인접한 행과 열의 크기도 변합니다. Ctrl+<마우스로 셀 경계선 이동> 은 다른 셀들도 비례해서 크기가 변합니다. Shift+<마우스로 셀 경계선 이동> 은 인접한 다른 셀들이 밀려서 이동합니다. Alt+<마우스로 셀 경계선 이동> 은 다른 셀들은 변화가 없고 선택한 셀만 이동합니다.
도표 바탕 그림 : 도표에 바탕 그림이나 다양한 그림 유형을 넣을 수 있습니다. 선택 모드에서 도표를 선택한 다음 "틀(D)"메뉴의 "도형 속성 지정(D)"을 사용합니다.
도표 한 셀만 선택 : 도표에서 셀 하나를 선택하려면 그 셀의 좌측 시작 위치에 마우스 포인터를 움직여 놓으십시오. 화살표 위에 "1"이 씌여져 있는 마우스 포인터는 셀 하나를 선택할 때 사용합니다.
도표 자동 유형 : 여러 가지 미리 준비된 도표 서식을 사용할 수 있습니다. 표를 만들고 나서, 표 전체를 선택한 다음 "표(B)" 메뉴의 "표 유형(S)", "자동 유형(S)" 을 선택하면 자주 사용되는 16가지 유형의 표 서식이 준비되어 있습니다.
도표 제목행 지정 : 여러 쪽에 걸쳐 있는 큰 도표에서 매 쪽의 상단 일부 셀을 선택하여 "제목행 지정(Alt+B, P, H)"하면 매 쪽마다 동일한 내용이 제목행으로 사용됩니다.
도표 소트 : 도표의 내용을 가나다순으로 정렬할 수 있습니다(Alt+B, R).
도표 셀 경계선 모양 변경 : 도표를 만든 다음, 일부 셀을 선택한 다음 도형 아이콘 바의 테두리 지정 아이콘을 사용하여 셀의 경계선을 다른 모양으로 바꿀 수 있습니다.
수식 편집기 : 복잡한 수식을 표현할 때 수식 편집기를 사용하면 편리합니다. "도구(T)"메뉴의 "수식 편집기(E)"를 사용합니다.
수식 편집기에서 빈 칸 입력 : 수식 입력 도중 스페이스를 입력하려면 <Ctrl+Space>를 누르십시오.
간접 입력창 : 빠른 입력을 위해 "입력(I)" 메뉴의 "기호 문자(S)", "간접 입력창(F11)"을 사용할 수 있습니다.
자동 교정 : 사용자가 등록한 단어에 대해서 자동으로 치환할 수 있는 기능으로 "도구(T)" 메뉴의 "자동 교정 설정(O)" 에서 그 값을 변경할 수 있습니다.
한/영 오타 변환 : 현재 입력한 내용을 영문 또는 한글로 변환하려면 "편집(E)" 메뉴의 "한/영 오타 변환(E)" 또는 (F4)를 누르십시오. 영역을 선택한 다음 실행하면 선택한 영역이 한/영 전환됩니다.
한/영 자동 전환 : 영문 약자 등을 사용할 때 원하지 않는 곳에서 한영 자동 전환된 것을 다시 취소하려면, 한영 자동 전환된 상태에서 바로 (F4)를 누르십시오. 한영 자동 전환된 내용이 다시 영문으로 되돌려집니다.
라벨 만들기 : 주로 사용되는 세 회사의 라벨 규격을 모두 지원하며, 여기에 라벨 규격을 더 추가할 수 있습니다. 또한 임의의 크기로 라벨을 새로 만들어 사용할 수도 있습니다.
각주/미주 내용이 있는 곳에서 Esc key를 치면 본문 중에 해당하는 각주/미주 mark 위치로 이동합니다.
각주/미주 mark가 있는 곳에서 Esc key를 치면 해당하는 각주/미주 내용이 있는 위치로 이동합니다.
각주/미주 내용 중의 각주/미주 번호 앞에서 마우스 왼쪽 버튼을 더블클릭 하면 본문 중에 해당하는 각주/미주 mark 위치로 이동합니다.
각주/미주 mark  번호의 앞에서 마우스 오른쪽 버튼을 더블클릭 하면 해당하는 각주/미주 내용이 있는 위치로 이동합니다.
미리 보기 화면에서 mouse left click하면 화면이 확대, right click하면 축소됩니다.
미리 보기 화면에서 Esc key를 치면 미리 보기가 해제됩니다.
Shift키를 누른 상태에서 선을 그리면 수평/수직/45도 사선을 그릴 수 있고 이동/복사 시 수평/수직 방향으로 이동 및 복사를 할 수 있습니다.
도형 모드에서는 정사각형 및 반지름이 같은 원 즉, 정사각형,정원 등을 그릴 수 있습니다.
그림틀이나 도형틀의 크기 조절 시 같은 크기 비율로 크기를 조정할 경우 해당 틀을 선택한 후 Shift키를 누른 상태에서 상하 좌우의 조절점을 움직이면 같은 크기 비율을 유지하면서 크기가 조절됩니다.
도표 모드에서는 Shift키를 누른 상태에서 구분선을 선택하면 도표선 오른쪽의 모든 셀들이 함께 움직이도록 되어 있습니다.
도표에서 셀을 연속으로 만들고 싶을 경우와 다시 커서를 뒤로 돌아가게 하는 방법 : 도표의 맨 마지막 오른쪽 끝 셀에서 탭(TAB)키를 치면 다음 줄에 바로 위와 같은 속성의 셀이 새롭게 생성됩니다. 커서가 다시 뒤로 가게 하려면 SHIFT + TAB키를 치면 됩니다.
차트를 실행할 경우 다양한 모습의 3차원 차트를 만드는 방법 : 차트를 실행한 후 3차원 차트를 지정하고 "만들기"를 하고 나면 차트 만들기 창에 선택한 3차원 차트가 나타나게 되는데 이 차트에 마우스를 대고 Ctrl키를 누르게 되면 마우스 포인터의 모양이 십자가 화살표 모양으로 변하게 되고 차트의 윤곽 크기 만큼의 상자가 점선으로 나타나게 되는데 이때 Ctrl키를 누른 상태에서 마우스의 왼쪽 버튼을 눌러 마우스의 위치를 옮겨 보면 차트가 마우스가 옮겨 지는 방향으로 360。까지 상하 좌우 회전을 자유롭게 할수 있고 마우스 버튼을 놓게 되면 마우스가 위치했던 방향으로 차트가 회전되어 나타나게 됩니다.
문서 내에서 열(세로)단위로 블록 지정 기능 : alt + 마우스 왼쪽 버튼을 누르면 열(세로)블록을 지정할 수 있습니다.
모눈종이 형태에 일정한 간격을 가진 글자를 입력하려고 하면 : 1)먼저 도형(사각형만 적용됨)을 그린 후 적당한 크기로 만들어 선택하여 주고 [틀 - 모눈 그리기]를 실행합니다. 자동 격자 그리기 대화상자에서 격자 그리기 정보에 가로 칸과 세로 칸의 수를 정의하여 주면 도형의 크기에 맞는 격자가 생성이 되고 글틀 삽입 선택 란을 체크하면 격자 부분에 글틀이 삽입되어 격자 안에 글자를 입력할 수 있습니다.  2)선택한 도형에 격자를 생성할 경우 도형과 격자는 한 object가 아니기 때문에 도형의 크기를 변화시켜도 격자선은 변화되지 않습니다. 만약 도형에 자동 격자를 적용시켰을 경우 크기를 변화시키려면 도형과 격자 전체를 묶은 후에 크기 변경을 해주시면 됩니다. 
기존 문서 열기, 다른 문서 불러오기 에서 여러 문서 한꺼번에 읽어오기 : 문서 열기 대화상자에서 Shift키나 Ctrl 키를 이용하여 한꺼번에 여러 문서를 읽어 올 수 있습니다. 원하는 파일들 중 첫번째 파일을 선택하고 Shift를 누른 채 마지막 파일을 선택하면 원하는 문서가 모두 선택(반전)됩니다. "열기"버튼을 누르면 선택한 문서가 순서대로 열리게 됩니다. 원하는 파일이 여기 저기 흩어져 있을 경우는 CTRL키를 이용하여 원하는 문서만 선택한 후 "열기"버튼을 누르면 역시 원하는 파일이 순서대로 읽히게 됩니다.
문서를 효과적으로 검색하려면 :  파일 메뉴의 "문서 관리"에서 "문서 요약"을 선택한 후 "중심어", "설명", "제목", "주제"등을 입력한 후 저장해두면 문서 관리기에서 효율적으로 문서를 찾을 수 있습니다.
찾기/바꾸기를 한 수위로 :   찾기/바꾸기에서 "조사 자동 바꾸기" 옵션을 선택하면 바꾼 단어의 조사가 자동으로 변경됩니다. 예) "키보드"를 "자판"으로 바꾸면 "키보드는"은 "자판은"으로 바뀌고 "키보드를"은 "자판을"로 자동 변환 됩니다.  또한 "어미 자동 바꾸기"옵션을 선택하면 자동으로 어미를 찾고 바꿀 수 있습니다.  예) "가다"를 "오다"로 바꾸면 "가서", "가니", "가고", "갔다" 등은 "와서", "오니", "오고", "왔다"등으로 바뀝니다. 이때 반드시 찾을 단어/바꿀 단어를 기본형(가다, 오다)으로 입력해야 합니다.
문장에 코멘트를 달고 싶을 때 : 본문 중 코멘트를 달고 싶은 부분을 선택한 후 "확장 기능 도구"툴바에 있는 "코멘트 붙이기"를 선택하면 "하이퍼 메모"대화 상자가 뜨고 이 대화상자에 코멘트를 입력해 두면 나중에 본문을 더블클릭하면 코멘트 내용을 볼 수 있습니다. 수정하고 싶을 때는 본문 중 코멘트가 있는 부분에 커서를 놓은 후 (편집 모드) "입력"메뉴의 "하이퍼 링크"를 선택하면 코멘트 내용을 수정할 수 있습니다.  
머리말과 꼬리말을 화면과 출력시 나타나지 않게 하려면 [보기-보기/ 감추기]의 “머리말 보기”나 “꼬리말 보기”선택된 부분을 해제하면 됩니다. 그러나 위와 같은 방법은 “머리말 보기”나“꼬리말 보기”를 다시 선택하면 나타납니다. 머리말과 꼬리말을 완전히 삭제하려면 [입력-머리말/꼬리말]-[적용 쪽 변경」 대화상자에서 “적용 영역 선택” 부분에 선택되어 있는 부분을 모두 해제하면 자동으로 삭제됩니다. 
그림이 많이 삽입된 문서일 경우 편집하다보면 속도가 느려지는데 이럴 경우에는 [보기-보기/감추기-그림 보기]의 체크를 풀어 주면 그림이 있는 영역에는 그림의 크기만한 글틀만 남겨지고 그림은 숨어 있게 되므로 편집 속도가 빨라집니다.
블록 설정 : 키보드의 CTRL키를 누른 상태에서 마우스 왼쪽 버튼을 누르면 문서 전체가 설정. 단어 범위 설정 : 단어의 중간 부분에 마우스 포인터를 위치 시킨 후에 마우스 왼쪽 버튼을 더블클릭  문장 및 단락 범위 설정 : 현재 커서가 위치한 부분에서 Shift키를 누른 상태에서 블록하고자 하는 부분의 끝 부분에 마우스의 위치를 옮긴 후 마우스 왼쪽 버튼을 누르면 특정 부분만 블록을 설정 할 수 있습니다.
강력해진 column marking(열(세로)단위로 블록 지정하는 기능) : Alt키를 누른 상태에서 마우스를 끌어 원하는 범위를 설정하면 열(세로)방향으로 범위를 지정할 수 있는데 열 단위로 블록이 지정되어 단락 전체가 아닌 단락의 특정한 부분 등을 어떤 형태로든 범위 설정이 가능하게 되어 기존에 일괄적인 column marking 의 불편함을 해소 하였습니다. 
표로 만든 문서를 Text로 바꾸는 방법 : 도표 안에 내용 중 Text로 바꾸고자 하는 부분을 블록 지정한 후 [표-표변환-표를 텍스트로]를 선택한 후 구분 기호 중 하나를 선택하면 선택된 구분 기호로 셀의 내용이 분리되어 text로 변환한다. 
도형의 자유로운 모양 변경 : 직선, 사각형, 둥근 사각형, 호 그리기 등으로 그려진 도형은 곡선/직선 변경에 의한 도형 변경이 실행되지 않습니다. 열린 다각형이나 닫힌 다각형, 곡선 그리기나 자유선 그리기 또는 파이 그리기 등을 이용한 도형을 선택한 후 선택 모드에서 도형 틀을 더블클릭하면 많은 꼭지점들이 나타납니다. 이 꼭지점들을 마음대로 움직여 도형을 변형시킬 수도 있습니다. [틀 → 도형 모양 변경]을 선택하거나  도형을 선택한 후 더블클릭하면 조절점이 생깁니다. 이때 조절점 가까이에 마우스를 놓으면 마우스 모양이 +  로 바뀌고 조절점을 끌어서 모양을 변경합니다. 
쪽 번호 설정 : 문서의 2번째 쪽부터 1번으로 번호를 매기고 싶을 때는 문서의 2번째 쪽에서 입력 메뉴의 "쪽 번호..."를 실행한 후 대화상자에서 쪽 번호 표시를 체크한 후 시작 쪽 번호를 1로 지정하고 확인하면 됩니다. 문서에 표시될 쪽 번호는 입력 메뉴의 "쪽 번호..."를 실행한 후 나타나는 대화상자에서 시작 쪽 번호, 상하/좌우 위치, 앞뒤 문자열, 서체 등 다양한 옵션을 사용할 수 있으며 번호 체계도 여러 단계에 걸쳐서 자유롭게 지정할 수 있습니다. 입력 메뉴의 쪽/날짜/시간 필드 입력 기능을 이용하면 문장 입력 중간에 쪽 번호나 날짜 시간 등을 자동으로 입력할 수 있습니다.
원고지/편지지/방안지 쓰기 : 편집 중인 문서를 원고지 형태로 전환하고자 할 때는 조판 메뉴의 "원고지/편지지" 항목 중 원고지 쓰기를 선택하면 됩니다. 현재 문서의 용지가 가로 폭이 큰 경우는 200자 원고지, 세로 폭이 큰 경우는 400자 원고지를 기본으로 적용합니다. 원고지 용지 형식을 바꾸고자 할 때는 양식 조판 메뉴의 "원고지/편지지" 항목 중 양식 설정을 선택하여 원하는 양식을 선택하면 됩니다. 논문 작성용 등은 보통 600자나 1000자 양식을 사용합니다.
원고지, 편지지 또는 방안지 양식에서 문서를 작성하다가 양식이 없는 기본 문서로 되돌리고 싶을 때는 조판 메뉴의 "원고지/편지지" 항목 중 해당 양식을 다시 선택하면 됩니다.
원고지/편지지의 양식 설정에서 사용자 정의를 할 수 있습니다. 양식의 가로 세로 칸수를 임의로 정의할 수 있으며 가로 칸수를 1로 하면 편지지 양식과 같이 처리됩니다. 양식 내부 한 칸의 크기를 좀더 크거나 작게 하고자 할 때는 용지 여백을 바꾸어 주면 자동으로 계산합니다.
원고지, 편지지 또는 방안지 양식에서도 서체 정보를 지정할 수 있습니다. 지정한 서체 크기가 양식의 한 칸 높이 보다 큰 경우는 양식의 칸 높이로 적용합니다.
원고지 양식에서는 원고지 쓰기 문법에 맞추어 단락의 시작 한 칸 띄기, 인용구 한 칸 띄기, 단락의 시작이라도 앞 문장을 이어받는 말(~할, ~하기에, ~하고, 등)은 한 칸 띄기 금지 등 기본적인 원고지 쓰기 방법을 자동으로 처리합니다. 자동 처리 기능을 원하지 않을 경우에는 원고지 양식 설정에서 "단락 첫 글자 들여쓰기" 선택을 취소하면 됩니다.
인용 부호나 겹낫표 등을 쉽게 입력하려면 도구 메뉴의 사용자 선택 사항의 초기 환경 설정에서 편집 환경에 있는 "한글 모드에서 자동 따옴표 및 겹낫표"를 선택한 후 한글 모드상에서 키보드의 {} [] '' "" 문자를 등을 입력하면 자동으로 『』「」‘ ’“ ”등의 문자로 바꾸어 줍니다.
문서를 효과적으로 검색하려면 :  파일 메뉴의 "문서 관리"에서 "문서 요약"을 선택한 후 "중심어", "설명", "제목", "주제"등을 입력한 후 저장해두면 문서 관리기 또는 문서 찾기를 이용해 효율적으로 문서를 찾을 수 있습니다.
문서 찾기: 훈민 문서 찾기를 이용하면, 지정된 문자열을 갖는 훈민 워드 문서를 검색할 수 있습니다. 파일 이름 검색의 경우 '*'를 입력하면 모든 훈민 워드 문서를 검색할 수 있습니다.
기본 프로그램 설정: 훈민 워드 i, 훈민 워드 i 라이트, 훈민 워드 i 뷰어 등 2개 이상의 훈민정음 프로그램이 등록되어 있는 경우 기본 프로그램 설정을 이용하면, 훈민 워드 문서 더블클릭 시 구동될 프로그램을 선택할 수 있습니다. 
미주/각주 상호 변환:미주나 각주가 라인에서 마우스 오른쪽 버튼을 누르면 미주 각주 상호 변환 메뉴가 나타납니다. 이 메뉴를 통해 미주를 각주로 또는 각주를 미주로 상호 변경할 수 있습니다. 여러 개의 미주나 각주를 변환할 때는 마우스와 시프트 키를 이용해서 여러 라인을 선택한 후 역시 마우스 오른쪽 버튼을 이용해서 변환할 수 있습니다.
문서 자동 요약 : 문서의 내용을 자동으로 요약해 줍니다. "도구(T)" 메뉴의 "문서 자동 요약(N)"이나 "기본 도구"바에 특수 문자 아이콘을 누르십시오.
조합형/고어 입력 : 이제 훈민 워드에서 조합형은 물론 50여만자의 한글 고어를 모두 입력할 수 있습니다. "한글 입력 상태 표시" 메뉴에서 "고어(O)"를 선택하십시오.
고어 자판 보기 : "한글 입력 상태 표시" 메뉴의 "고어 자판 보기"를 선택하십시오.
아래아 한글 특수 문자 : "문자표"의 "아래아 한글 특수 문자" 탭에서 새로이 추가된 특수 문자들을 입력할 수 있습니다.
"문자표"의 "고어 입력" 탭이 어디 갔지? : 이제 훈민 워드에서 조합형은 물론 50여만자의 한글 고어를 모두 입력할 수 있습니다. "한글 입력 상태 표시" 메뉴에서 "고어(O)"를 선택하십시오.
강조점, 개요 유형 지정의 시작 위치 여백에서 공백 문자 입력 후 본문 쓰기를 선택하면 강조점이나 개요 입력 시 특별히 시작 위치를 조절할 필요 없이 공백 문자 가격만큼 적당한 거리를 유지하고 본문이 시작됩니다.
그림이나 많은 양의 글자를 복사하면 훈민 워드를 종료할 때 클립 보드의 내용을 지울지를 물어봅니다. 이게 번거로우면 환경 설정의 편집 환경에서 종료시 클립 보드의 내용(100KB 이상)을 지울지 확인 단추를 끄면 더 이상 프로그램 종료시 물어보지 않습니다.
이동 글틀의 높이와 너비를 입력하는 양에 따라 자동으로 조절되기를 원하면 테두리 지정 문답 상자로 들어가서 이동 글틀 높이 자동 조절과 이동 글틀 너비 자동 조절 버튼을 각각 선택해 주면 됩니다.
모든 틀의 문장 흐르기 조정을 하고자 할 경우 틀을 선택한 후 더블클릭을 하면 해당 모든 문답 상자에서 문장 흐르기를 지정해 줄 수 있습니다.
문서 편집 중에 한영 맞춤법을 수행하고 싶으면 자동 교정 설정에서 편집 시 철자 오류 검사함을 선택해 주면 됩니다. 그리고 본문 중 철자 오류로 인하여 밑줄이 그어져 있는 단어에 마우스 오른쪽 버튼을 클릭하면 해당 글자의 철자가 맞는 후보어 들이 나옵니다. 그리고 그 후보어를 선택하면 잘못된 단어를 바꾸어 줍니다.
다른 이름으로 저장 : 아래아 한글97버전으로 저장 가능합니다. 텍스트, 도표, OLE, 그림 모두 지원합니다. 단, 훈민정음에서만 지원하는 도형의 일부는 메타 파일로 저장됩니다.
