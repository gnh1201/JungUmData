# JungUmData

JungUmData (Examples of GUL, HST, WMF, FRM, and SBL Files)

> 훈민정음 데이터 (GUL, HST, WMF, FRM, SBL 파일 예제)

These files were extracted from Samsung Electronics' Hunminjeongeum Global 2005, and Hunminjeongeum Office-i 2001.

> 이 파일들은 삼성전자의 훈민정음 Global 2005, 훈민정음 오피스i 2001 에서 추출되었습니다.

This collection was gathered as part of the Catswords Digital Data Format Dictionary project by [Catswords Research](https://catswords.com).

> 이 자료는 [캐츠워즈리서치](https://catswords.com)의 Catswords Digital Data Format Dictionary 프로젝트의 일환으로 수집되었습니다.
